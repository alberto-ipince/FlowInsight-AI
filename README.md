# FlowInsight AI

> **Descripción temporal** — Este documento será reemplazado conforme el proyecto evolucione.

## 📋 Descripción General

FlowInsight AI es una plataforma de análisis inteligente diseñada para transformar datos en insights accionables mediante técnicas modernas de inteligencia artificial y visualización interactiva.

## 🏗️ Arquitectura del Proyecto

```
Proyecto 2/
├── assets/          # Recursos estáticos (imágenes, fuentes, etc.)
├── backend/         # API REST con FastAPI (Python)
├── data/            # Conjuntos de datos y archivos de muestra
├── database/        # Migraciones, seeds y esquemas de base de datos
├── docker/          # Configuraciones específicas de Docker
├── docs/            # Documentación técnica y funcional del proyecto
├── DOCUMENTACION/   # Entregables de la asignatura
├── frontend/        # Aplicación web con React + TypeScript + Vite + Tailwind CSS
├── scripts/         # Scripts de automatización y utilidades
├── tests/           # Pruebas unitarias, de integración y end-to-end
├── .gitignore
├── .env.example
├── docker-compose.yml
└── README.md
```

## 🛠️ Stack Tecnológico

| Capa        | Tecnología                          |
|-------------|-------------------------------------|
| Frontend    | React, TypeScript, Vite, Tailwind CSS |
| Backend     | Python, FastAPI                     |
| Base de datos | PostgreSQL                        |
| Infraestructura | Docker, Docker Compose           |
| Control de versiones | Git                        |

## 🚀 Inicio Rápido (Work in Progress)

> Las instrucciones detalladas se agregarán en sprints posteriores.

1. Clonar el repositorio.
2. Copiar `.env.example` a `.env` y ajustar las variables.
3. Ejecutar `docker-compose up` para levantar los servicios.
4. Acceder al frontend en `http://localhost:5173` y al backend en `http://localhost:8000`.
